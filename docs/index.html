一个账号，三种客户端

  • Windows 桌面端
  • 安卓 App
  • 网页端 / PWA
  • iOS 添加到主屏幕
  • 连接码直连
  • 局域网直连

也可以不用账号：9 位连接码、同网段识别码，或者直接把设备装进手机浏览器。

把远程这件事，做得简单一点

该有的都有，而且跑在你自己的网络和服务器上。

屏幕墙

所有在线设备的实时缩略图排成一面墙，点开即控，不用来回切窗口。

点开即控

鼠标、键盘、剪贴板、多显示器切换；同账号设备免确认，直连仍逐次确认。

群控同步

一次点击、拖动或输入广播到多台机器，适合机房、展厅和批量操作。

文件传输

拖拽即传，断点续传、SHA256 校验、整目录、3 路并发，双向都行。

声音双向

Opus 编码、码率自适应；远端声音、本机麦克风与回声消除都支持。

自建账号服务器

单文件 Rust 服务端：账号、设备目录、在线状态、审计与自动更新都在自己手里。

三步开始

不装服务端，也能在同一局域网里直连使用。

  1. 下载并安装客户端

    Windows 安装包约 9 MB，装完打开就能被控，也能当主控。

  2. 局域网里直接用连接码或识别码

    不需要账号，也不需要服务器；同一网段输入 9 位识别码就能找到设备。

  3. 要跨网段，就起一台自己的服务器

    单文件服务端，同时托管网页端；登录同一个账号，手机浏览器也能控。

    ./screenwall-server run --config server.toml --web-dir web/dist
